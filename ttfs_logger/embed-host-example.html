TTFS 内嵌示例 · Embed parent (same origin)

父页面与 iframe 必须同源（同一 scheme + host + port），否则拿不到 contentWindow.TTFS，也无法传 MediaStream。 跨端口可用反向代理：例如 Vite server.proxy 把 /ttfs 指到 http://127.0.0.1:8765。

父页面最小接入代码

const iframe = document.getElementById('ttfsFrame');

window.addEventListener('message', (ev) => {
  if (ev.data?.source !== 'ttfs-embed') return;
  // 生产环境请校验 ev.origin
  if (ev.data.type === 'ttfs-mic-ready') {
    const w = iframe.contentWindow;
    const micClone = w.TTFS.cloneMicForConsumer(); // 交给 RTC / WS，勿再 getUserMedia
    console.log('mic clone', micClone);
  }
  if (ev.data.type === 'ttfs-latency-ms') {
    console.log('latency ms', ev.data.ms);
  }
});
