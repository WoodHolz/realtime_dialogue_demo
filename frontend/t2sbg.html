芝麻背调证明人访谈（T2S 纯文本 → 语音）

支持直接以文本形式发起对话，或使用麦克风说话（豆包 ASR 识别后发送给语音对话模型）。 服务端使用 input_mod: "text"，自动保证流式链路完整性。 语音上行链路：Browser → Backend → Hush 降噪（weya-ai/hush）→ 本地 VAD 判停 → 豆包 ASR；Hush 未就绪时自动跳过。 TTFS 延迟面板已内联在本页：点 Start Session 时会自动请求 TTFS 麦克风（也可手动点 Mic）；AI TTS 自动接入 Playback 测光。停止会话会 TTFS.stop()。

点击 Start 建立会话，然后输入文本或语音。

Mode: t2s

判停 / VAD

Silero 检测说话与静音；判停可对比 Smart Turn v3、LiveKit audio TurnDetector v1（推荐）、旧版 text EOU。

TTFS 麦克风 / 延迟面板（本页内联）

Start Session 会自动调用 TTFS.startMic() 并 cloneMicForConsumer()。亦可手动点 Mic。端到端延迟 = 本轮麦克风 utterance 结束（Hang ms 静默）→ 下一轮扬声器输出起始（Playback 能量上升沿）；Stop 会清空读数。
