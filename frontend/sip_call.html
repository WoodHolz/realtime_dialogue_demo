SIP 外呼测试

选择外显号、填写被测手机号，发起催授权外呼。被叫会自动加 a1 前缀。

号池来自 config.json → outbound.display_numbers

实际拨打：a1…

就绪。填写号码后点击发起。

} function updatePreview() { const called = withPrefix(el.phone.value); el.calledPreview.textContent = called || (calledPrefix + "…"); } function setStatus(text, isErr) { el.status.textContent = text;
